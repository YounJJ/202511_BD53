## 📂 Repository Structure

The repository is organized by learning themes and modules:

* **`lab_python`**: Practice files for Python core syntax and data analysis libraries (Pandas, Seaborn, etc.).
* **`lab_ml`**: Implementation of Machine Learning algorithms (Regression, Classification, Clustering) and preprocessing techniques.
* **`lab_sql`**: SQL query writing and database schema construction using Oracle DB.
* **`lab_pycharm`**: Modular programming and Oracle DB integration projects within the PyCharm IDE.
* **`self_study_python`**: Independent study, before starting the course.

---

## 📝 Detailed Curriculum & Learnings

### 1. Python Programming & Data Analysis (`lab_python`, `self_study_python`)
Mastered core Python features and essential libraries for data handling.

* **Python Essentials:** Control flow (if, for, while), functions, OOP (Classes), and Exception handling.
* **Data Structures:** Advanced usage of Lists, Tuples, Dictionaries, and Sets.
* **Data Analysis Libraries:**
    * **Pandas:** DataFrame manipulation, handling missing values (`fillna`), data merging (`merge`), and grouping (`groupby`).
    * **Visualization:** Conducted Exploratory Data Analysis (EDA) using Matplotlib and Seaborn.
    * **NumPy:** High-performance numerical computation and multi-dimensional array operations.

### 2. Machine Learning (`lab_ml`)
Implemented and optimized machine learning models using Scikit-learn.

* **Supervised Learning:**
    * **Regression:** Linear Regression, Ridge/Lasso Regularization, and Gradient Descent.
    * **Classification:** KNN, Logistic Regression, Decision Trees, and Ensemble methods (Random Forest).
* **Unsupervised Learning:** K-Means Clustering and Dimensionality Reduction using PCA.
* **Model Evaluation:** Analysis of performance metrics including Confusion Matrix, Precision, Recall, and F1-score.

### 3. Database & SQL (`lab_sql`)
Practiced efficient data storage and extraction using Oracle SQL.

* **Basic SQL:** Data retrieval (`SELECT`), filtering (`WHERE`), and sorting (`ORDER BY`).
* **Advanced SQL:** Aggregate functions, JOIN operations (Inner, Outer), and complex Subqueries.
* **DB Management:** Table creation/modification (`DDL`) and data manipulation (`DML`) with integrity constraints.

### 4. Application Development (`lab_pycharm`)
Developed modular code and integrated external databases in a professional IDE environment.

* **Modularization:** Separated logic into packages like `myutil` and `oracleutil` for better reusability.
* **DB Connectivity:** Developed custom logic to perform CRUD operations by connecting Python with Oracle DB.

## 📝 Detailed Curriculum & Learnings

### 1. Python Programming & Data Analysis (`lab_python`, `self_study_python`)
데이터 분석의 기초가 되는 Python 언어의 핵심 기능과 데이터 핸들링 라이브러리를 학습했습니다.

* **Python Essentials:** 제어문(if, for, while), 함수, 객체 지향 프로그래밍(Class), 예외 처리
* **Data Structures:** List, Tuple, Dictionary, Set의 활용
* **Data Analysis Libraries:**
    * **Pandas:** DataFrame 조작, 데이터 병합(`merge`), 그룹화(`groupby`)
    * **Visualization:** Matplotlib와 Seaborn을 활용한 EDA(탐색적 데이터 분석) 수행
    * **NumPy:** 다차원 배열 연산 및 통계 함수 활용

### 2. Machine Learning (`lab_ml`)
Scikit-learn을 활용하여 주요 머신러닝 모델의 원리를 이해하고 구현했습니다.

* **Supervised Learning:**
    * **Regression:** 선형 회귀, 릿지/라쏘 규제, 경사 하강법
    * **Classification:** KNN, 로지스틱 회귀, Decision Tree, 앙상블(Random Forest)
* **Unsupervised Learning:** K-Means 군집화, PCA 차원 축소
* **Evaluation:** 혼동 행렬(Confusion Matrix), 정밀도, 재현율, F1-score 등 성능 지표 분석

### 3. Database & SQL (`lab_sql`)
데이터의 효율적인 관리와 추출을 위해 Oracle SQL 실습을 진행했습니다.

* **Basic SQL:** 데이터 조회(`SELECT`), 필터링(`WHERE`), 정렬(`ORDER BY`)
* **Advanced SQL:** 집계 함수, JOIN(Inner, Outer), 서브쿼리 활용
* **DB Management:** 테이블 생성/수정(`DDL`), 데이터 삽입/수정/삭제(`DML`) 및 제약 조건 설정

### 4. Application Development (`lab_pycharm`)
실무 환경과 유사한 IDE(PyCharm)에서 코드를 모듈화하고 외부 DB와 연동하는 실습을 수행했습니다.

* **Modularization:** 기능을 `myutil`, `oracleutil` 등 패키지 단위로 분리하여 관리
* **DB Connectivity:** Python과 Oracle DB를 연동하여 실제 데이터를 CRUD 하는 로직 구현
